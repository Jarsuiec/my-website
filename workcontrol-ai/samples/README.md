# Примеры файлов для импорта

Все данные вымышленные (домен `example.invalid`). Используйте их, чтобы проверить импорт:

| Файл | Что демонстрирует |
|---|---|
| `przyklad-allegro.eml` | одно письмо EML: «paczka nie dotarła» → задача «Проверить доставку» |
| `gmail-takeout-przyklad.mbox` | MBOX как из Google Takeout: запрос фактуры + ваш ответ (метка Sent) + немецкая рекламация |
| `zgloszenia-przyklad.csv` | таблица обращений (колонки from, name, subject, date, message, source) |
| `WhatsApp Chat with Hurtownia Marek.txt` | экспорт чата WhatsApp; в Настройках укажите имя «Ja», чтобы ваши сообщения распознались |

Чтобы ваши ответы распознавались в почте, укажите в Настройках адрес `sklep@example.invalid`.
Загрузите файлы второй раз — дубликаты не появятся.
