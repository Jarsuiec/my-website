# Рекламный ролик e-commerce (код → видео)

Готовое видео: `media/ecommerce-promo-reels.mp4` — 1080×1920, 60 fps, 70 сек, голос + музыка.

Как собирается:
1. `voice.py` — расшифровка голоса (Whisper), паузы ужимаются, речь ускоряется ×1.1 → `voice.wav` + `timing.json` (время каждого слова).
2. `promo.html` — вся анимация. Каждое слово на экране появляется в момент, когда его произносят (берётся из `timing.json`).
3. `render.js` — Chromium рендерит кадры → ffmpeg (`node render.js video out.mp4 60 0 4237`; `stills` — отдельные кадры для проверки).
4. `music.py` — музыка и звуковые эффекты синтезируются кодом (бит, бас, аккорды, вжухи, удары), с приглушением под голос.
