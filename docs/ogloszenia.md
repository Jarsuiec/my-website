# Объявления: OLX, Allegro Lokalnie, Facebook

**Правила, чтобы объявление не удалили:**
- В тексте объявлений на OLX **не ставь ссылки** на сайт или Telegram: правила OLX запрещают ссылки на внешние сервисы. Клиент пишет тебе в чат OLX или звонит, а ссылку на сайт ты отправляешь уже в переписке.
- **Одно объявление = одна услуга.** Не копируй одинаковый текст в несколько объявлений.
- **Фото только свои**: твои инструменты, твой стол, ноутбук в разборе, чистый радиатор. Без картинок из интернета.
- В категории «Usługi» OLX может брать плату сверх бесплатного лимита. Начни с бесплатных объявлений (1–2), посмотри отклик и только потом решай, платить ли за остальные.

Рубрика на OLX: **Usługi → Usługi informatyczne** (или *Serwis AGD/RTV → Komputery i konsole*). Локация: Warszawa, второе объявление — Pruszków.
