# PC Master Warszawa — сайт

Сайт компьютерной помощи на русском, украинском и польском языках. Форма заявок работает через Netlify Forms.

## Файлы

| Файл | Что внутри | Нужно ли менять |
|---|---|---|
| `config.js` | телефон, Telegram, WhatsApp, цены | **да, перед публикацией** |
| `index.html` | структура страницы | редко |
| `script.js` | тексты на 3 языках, работа формы | когда меняешь тексты |
| `styles.css` | внешний вид | редко |
| `docs/biznes-plan.md` | бизнес-анализ и план на 30 дней | читать |

## Шаг 1. Заполнить контакты

Открой `config.js` на GitHub → значок карандаша (Edit) → впиши телефон, Telegram, WhatsApp и свои цены → **Commit changes**.
Если поле оставить пустым (`""`), кнопка просто не появится на сайте.

## Шаг 2. Опубликовать на Netlify (бесплатно)

1. Зайди на https://app.netlify.com и войди через GitHub.
2. **Add new site → Import an existing project → GitHub**.
3. Выбери репозиторий `Jarsuiec/my-website` и ветку (`main` или ту, где лежит сайт).
4. Build command — оставь **пустым**. Publish directory — `.` (точка).
5. **Deploy**. Через минуту сайт будет доступен по адресу вида `что-то.netlify.app`.
6. **Site configuration → Change site name** → например `pcmasterwarszawa` (если это имя свободно).

## Шаг 3. Получать заявки

1. В Netlify: **Forms** → включи обнаружение форм (Enable form detection), затем сделай **новый деплой** (Deploys → Trigger deploy).
2. **Forms → Form notifications → Add notification → Email** → твоя почта.
3. Отправь тестовую заявку со своего телефона и проверь, что письмо пришло.

Бесплатный план Netlify принимает ограниченное число заявок в месяц, для старта этого с запасом.

Позже (неделя 2–3 плана) подключим Make: заявка → строка в Google Sheets + сообщение в Telegram.
