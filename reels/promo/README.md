# PC MASTER WARSZAWA — рекламный ролик (код-проект)

Вертикальный ролик 1080×1920, 30 fps, H.264/AAC, ~56 с. Голос — твоя запись из ElevenLabs
(`assets/voice.mp3`): без изменений скорости и порядка, только выравнивание громкости.
Всё остальное (3D, графика, субтитры, музыка, эффекты) генерируется кодом, без стоков и чужих треков.

## Что где

| Файл | Что это |
|---|---|
| `promo.json` | **Контент**: Telegram, имя, бренд, города, услуги, приветствия, текст переписки, тайминги сцен, клипы |
| `script.json` | Текст озвучки по речевым отрезкам + выделение слов в субтитрах (`[голубой]`, `{оранжевый}`, `<зелёный>`) |
| `words.mjs` | Считает время каждого слова → `words.json` и **`subtitles.srt`** |
| `src/scenes.js` | 10 сцен; каждое событие привязано к слову озвучки через `W('слово')` |
| `src/models.js` | Процедурные 3D-модели: ноутбук, турбина, HDD, SSD, кулер, CPU, игровой ПК, бак, кружка |
| `src/brand.js`, `brand/` | Логотип (SVG/PNG) и иконка Telegram |
| `audio.py` | Музыка по сценам + звуковой дизайн (всё синтезировано, лицензионно чисто) |
| `render.mjs` | Рендер: параллельные браузеры → 60 fps → motion blur → 30 fps + сведение звука |
| `extras.mjs` | Обложка, PNG логотипа, отдельная финальная заставка |
| `PROMPTS.md` | Промпты для живых кадров (Варшава, человек с ноутбуком, макро-чистка, мусорный бак) |

## Как поменять контакт, тексты, услуги

1. Правишь `promo.json`: `telegram`, `services`, `tagline`, `chat`…
2. Если менялась озвучка — кладёшь новый MP3 в `assets/voice.mp3`, правишь отрезки в `script.json`
   (времена пауз: `ffmpeg -i assets/voice.mp3 -af silencedetect=noise=-40dB:d=0.12 -f null -`) и запускаешь `node words.mjs`.
   Сцены сами подстроятся: они ищут свои слова в разметке.
3. Сборка:

```bash
cd reels && npm install                 # один раз (three.js, шрифты, playwright)
node promo/words.mjs                    # субтитры + SRT
python3 promo/audio.py                  # музыка и эффекты
node promo/render.mjs --workers 2       # ~50 мин на CPU → promo/build/pc-master-promo.mp4
node promo/extras.mjs                   # обложка, логотипы, endcard.mp4
node promo/preview.mjs /tmp 9.8 24.5    # быстрые кадры для проверки
```

## Честность контента
- Температура в сцене чистки помечена «иллюстрация», скорости SSD не показаны как тест; есть сноска
  «Результат зависит от характеристик компьютера».
- Цены не придуманы: в переписке «назову цену до начала работы».
- Лица Ярослава нет: в кадре только техника; для живых кадров — руки/силуэт (см. `PROMPTS.md`).
