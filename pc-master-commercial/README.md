# PC MASTER — «Вторая жизнь твоего ПК»

Рекламный ролик 9:16 для соцсетей (Reels / TikTok / Shorts). Весь ролик собирается кодом, без стоковых видео и чужих логотипов:

- **3D-сцены**: Three.js через Remotion. Плата ATX, башенный кулер, вентиляторы, HDD, M.2 SSD, видеокарта, корпус, ноутбук смоделированы с реальными пропорциями.
- **Типографика и интерфейсы**: React. Все надписи векторные, генеративных картинок с текстом нет.
- **Музыка и звуковые эффекты**: синтез на Python (NumPy/SciPy). Звуки рассчитываются математически, поэтому трек оригинальный и не требует лицензии.
- **Сборка**: FFmpeg. H.264 1080×1920, 30 fps, AAC stereo 320 кбит/с, громкость −14 LUFS (стандарт соцсетей).

### Что изменилось в V2

- **Голос Ярослава** из ElevenLabs. Каждая фраза выровнена по тексту сценария, монтаж подогнан под речь, а субтитры синхронизированы с голосом по словам.
- **SSD и Windows**: тёплый «медленный» HDD с зависшей загрузкой → резкий наезд камеры с радиальным размытием движения → SSD с бегущими голубыми импульсами → проводка камеры вдоль накопителя → быстрая установка Windows и отзывчивый рабочий стол. Музыка в это время звучит глухо и раскрывается в момент появления SSD.
- **Макросъёмка обслуживания**:
  - радиатор в пыли и продувка сжатым воздухом;
  - старая паста стирается салфеткой, на крышку процессора с гравировкой наносится новая «горошина»;
  - кулер устанавливается, вентилятор раскручивается, и свет меняется с оранжевого на голубой.
  - Малая глубина резкости.
- **Диагностика** стала светлее и холоднее. Скан идёт по плате, контуры узлов подсвечиваются, по дорожкам бегут сигналы, а в карточке результата видна найденная причина.
- **Типографика**: выстроена иерархия, субтитры и второстепенные надписи стали крупнее, контраст выше. Плашка Telegram в финале стала крупнее.
- **Звук**: чистый басовый удар на PC MASTER, мягкий воздух при чистке, технологичный импульс на SSD. Голос на ~10 дБ громче подложки, а внутри каждой фразы работает адаптивное приглушение музыки.

## Как добавить твой голос из ElevenLabs

### Вариант А. Через API (тайминг подгоняется автоматически, субтитры идут по словам)

1. Скопируй `.env.example` в `.env` и впиши в него `ELEVENLABS_API_KEY`. Файл `.env` не попадает в git, а ключ не оказывается в коде ролика.
2. Выполни `npm run voice -- --list`, найди в списке свой клон и впиши его id в `ELEVENLABS_VOICE_ID`.
3. Выполни `npm run voice`. Скрипт озвучит 12 реплик (у каждой учитываются соседние, чтобы интонация была цельной), измерит их реальную длину и сохранит тайминг слов для субтитров.
4. Выполни `npm run build`.

### Вариант Б. Готовый MP3 с сайта ElevenLabs (так сделаны V2 и FINAL)

1. Озвучь текст на сайте одним файлом, с паузами между фразами (как в сценарии).
2. Выполни `npm run voice:import -- путь/к/файлу.mp3`. Скрипт `audio/align_voice.py` находит фрагменты речи между паузами и раскладывает по ним предложения сценария методом динамического программирования, сверяя их длительность с длиной текста. Онлайн-распознавание речи для этого не нужно. В результате получаются 12 реплик с таймингом слов.
   Можно также передать папку с файлами `L01.mp3` … `L12.mp3`.
3. Прослушай нарезку в `public/voice/` и запусти `npm run build`.

**Речь никогда не ускоряется.** Если фраза длиннее своей сцены, скрипт удлиняет сцену с шагом 0.5 с, чтобы склейки остались в музыкальной сетке, и пересчитывает музыку. Отчёт об изменениях выводится в консоль, а старый тайминг сохраняется в `timeline.json.bak`.

Под голос музыка приглушается на 12 дБ, а там, где подложка особенно плотная, внутри фразы дополнительно. В паузах музыка и акценты возвращаются в полную силу. Голос слегка компрессируется и выводится примерно на 10 дБ громче подложки.

## Как поменять Telegram, надписи, длительность

| Что | Где |
|---|---|
| Telegram, названия услуг, география, все надписи в кадре | `src/config/brand.ts` |
| Длительность сцен, текст озвучки, произношение (`tts`) | `src/config/timeline.json` |
| Отрезки 15-секундной версии | `src/config/cut15.json` |
| Где скрыты нижние субтитры | `timeline.json` → `subtitles.hideInScenes` |

После правки выполни `npm run build` (основная версия) или `npm run build:15`. Музыка и эффекты строятся от тех же таймингов, поэтому синхронизация сохраняется при любом изменении длительности.

Посмотреть ролик в браузере и пролистать кадры можно командой `npm run studio`.

## Установка (один раз)

```bash
cd pc-master-commercial
npm ci
pip install -r requirements.txt     # numpy, scipy
```

Нужны Node 20+, Python 3.10+, FFmpeg и Chromium. Remotion скачивает Chromium сам. Если браузер уже установлен, путь к нему передаётся через переменную `REMOTION_BROWSER`.
Рендер работает и без видеокарты (программный WebGL), но на 4 ядрах полный ролик рендерится около часа. Рендер идёт кусками по сценам: если он прервётся, повторный `npm run build` дорисует только недостающие кадры.

## Структура

```
src/config/      brand.ts (тексты), timeline.json (тайминг, озвучка), cut15.json, subs.js (логика субтитров)
src/scenes/      S01Hook … S10CTA — по одному файлу на сцену
src/three/       3D: модели комплектующих, материалы, процедурные текстуры, свет, постобработка
src/components/  типографика, логотип, субтитры, плёночное зерно
audio/           engine.py (синтезатор), music.py (трек), sfx.py (саунд-дизайн), mix.py (сведение, приглушение под голос), align_voice.py (выравнивание озвучки по тексту)
scripts/         build.mjs (полная сборка), elevenlabs-voice.mjs, import-voice.mjs, subtitles.mjs, stills.mjs (контактный лист кадров)
```
